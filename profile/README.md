## 🌍 Our Mission
The **Open Typography Foundation** is an international open-source institution dedicated to archiving, cataloging, standardizing, and distributing free typefaces across the world's major writing systems. We provide designers, software engineers, and institutions with production-ready font packages compliant with the **SIL Open Font License 1.1**, **Apache 2.0**, and **CC0 Public Domain**.

## 🚀 Interactive Tools & Utilities

* 🌐 [**Live Web Font Previewer**](https://mohammadgolamrabbii.github.io/typography/): Interactive browser-based specimen tester supporting real-time typing, font size adjustments, and multi-script switching.
* 💻 [**`get-openfonts` CLI**](https://github.com/mohammadgolamrabbii/get-openfonts): Instant terminal font package installer (`npx get-openfonts list`, `npx get-openfonts download <name>`).
* 📚 [**Awesome Open Typography**](https://github.com/mohammadgolamrabbii/Awesome-Open-Typography): Curated list of font editors, WOFF2 converters, pairing algorithms, and licensing guides.
* 🪣 [**Enterprise Bitbucket Mirrors**](https://bitbucket.org/golamrabbii): High-availability enterprise repository mirrors on Atlassian Bitbucket.
* 📋 [**Jira Cloud Roadmap & Task Kanban**](https://golamrabbii.atlassian.net/jira/software/projects/KAN/boards/1): Enterprise agile roadmap managing archive indexing, optimizations, and releases.
