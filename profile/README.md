## 🌐 Our Mission
The **Open Typography Foundation** is an international open-source institution dedicated to archiving, cataloging, standardizing, and distributing free typefaces across the world's major writing systems. We provide designers, software engineers, and institutions with production-ready font packages compliant with the **SIL Open Font License 1.1**, **Apache 2.0**, and **CC0 Public Domain**.

> ### ⚡ Instant Terminal 1-Click Installers (Zero Rate-Limits)
> **🐧 Linux / macOS Bash:**
> ```bash
> curl -fsSL https://mohammadgolamrabbii.github.io/typography/install.sh | bash -s -- all
> ```
> *(Installs to `~/.local/share/fonts/opentypography/` and runs `fc-cache -f`)*
> 
> **🪟 Windows PowerShell:**
> ```powershell
> irm https://mohammadgolamrabbii.github.io/typography/install.ps1 | iex
> ```
> *(Registers directly into Windows Registry with zero reboot required)*
