## 🌐 Our Mission
The **Open Typography Foundation** is an international open-source institution dedicated to archiving, cataloging, standardizing, and distributing free typefaces across the world's major writing systems. We provide designers, software engineers, and institutions with production-ready font packages compliant with the **SIL Open Font License 1.1**, **Apache 2.0**, and **CC0 Public Domain**.
